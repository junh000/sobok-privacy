소복 개인정보 처리방침

시행일: 2026년 10월 29일 · 1.14.0: 음성입력·번역·이모지 검색 포함

이모지 검색

기기에 포함된 Unicode·CLDR 목록에서 이모지의 한국어·영어 이름과 검색어를 비교합니다. 검색어는 키보드가 열린 동안의 메모리에서만 처리하며 현재 입력 중인 앱의 입력란에 자동으로 전달하지 않습니다. 사용자가 고른 이모지 문자만 현재 입력란에 전달합니다. 검색어와 이모지 선택 이력을 파일·설정·서버에 저장하거나 전송하지 않으며 키보드를 닫거나 입력 대상이 바뀌면 검색어를 비웁니다. 삼성 등 다른 키보드의 최근 사용 기록을 읽지 않습니다.

1. 입력 정보의 처리

소복은 사용자가 누른 키를 현재 입력 중인 앱에 전달하기 위해 처리합니다. 한글 조합에 필요한 짧은 입력 버퍼는 메모리에서만 유지하며 입력 종료·입력 대상 전환 시 비웁니다. 추천 단어를 켠 경우 현재 단어를 기기 안의 기본 사전과 비교하며, 사용자 사전을 학습하거나 추천에 사용한 단어를 저장하지 않습니다. 복사한 항목 붙여넣기가 켜져 있으면 키보드가 열린 동안 현재 클립보드의 텍스트 또는 사진을 기기 안에서 읽어 붙여넣기 칸에 표시합니다. 비밀번호 입력란에는 표시하지 않으며, 민감한 항목으로 표시된 내용은 미리보기에서 숨깁니다. 사진 미리보기는 메모리에서만 처리합니다. 사용자가 붙여넣기를 눌렀을 때만 현재 입력 중인 앱에 텍스트 또는 사진을 전달합니다. 사진은 해당 입력란이 사진 입력을 지원해야 하며 일시적인 읽기 권한을 함께 전달합니다. 클립보드 내용과 사진을 파일로 저장하거나 서버에 전송하지 않고, 키보드가 닫히면 표시 중인 내용을 비웁니다. 일반 키보드 입력 문장과 비밀번호, 연락처, 위치를 소복 서버에 저장하거나 전송하지 않습니다. 번역 SDK의 별도 진단 정보 처리와 외부 음성인식 앱에 대한 설명은 아래를 확인하세요. 입력을 전달받는 상대 앱의 데이터 처리는 해당 앱의 개인정보 처리방침에 따릅니다.

사진 기준 키 위치 맞춤

사용자가 파일 선택창에서 직접 선택하거나 ‘복사한 캡처 사용’을 눌러 불러온 키보드 전체 화면 캡처를 기기 안에서 일시적으로 읽고 키 표면의 사각형 좌표를 분석합니다. 사진 속 문장을 해독하거나 입력 내용을 학습하지 않습니다. 사진을 앱 파일로 복사하거나 서버로 전송하지 않으며, 적용 또는 화면 종료 시 표시용 사진을 메모리에서 해제합니다. 사용자가 확인 후 적용한 키 위치·크기와 화면 비율만 설정으로 저장합니다. 실제 터치 영역은 인접 키 사이를 나누어 구성하며, 다른 키보드 앱의 내부 터치 설정을 읽지 않습니다.

클립보드 열기 기능은 소복 키보드를 열어 둔 동안 확인한 최근 항목을 최대 12개까지 메모리에만 임시 보관해 선택하도록 합니다. 키보드를 닫거나 입력 대상이 바뀌면 목록을 비웁니다. 민감한 항목은 이력에 보관하지 않으며 클립보드 내용과 사진을 파일 또는 서버에 저장하지 않습니다.

2. 기기 안에 저장되는 설정

선택한 디자인과 소리, 볼륨, 진동, 무음 모드 설정, 키보드 높이·배열 기준·하단 여백·기존 키보드에서 측정한 표시 높이·시스템 하단 높이·숫자 줄 유무·상단 도구 높이·하단 여백, 입력 언어, 화면 모드, 사진 기준 키 위치·크기·화면 비율, 도구·추천·이모지·숫자 줄·복사한 항목 표시, 길게 누르기, ASMR, 입체모드 설정만 기기 안에 저장합니다. 서버에 저장하지 않으며 클라우드 백업과 기기 간 데이터 이전을 사용하지 않습니다. 앱 삭제 또는 기기 설정의 앱 데이터 삭제로 지울 수 있습니다.

3. 권한과 외부 서비스

소복은 진동 권한과 번역 언어팩·SDK 통신을 위한 인터넷·네트워크 상태 권한을 사용합니다. 마이크·카메라·연락처·위치·갤러리 전체 접근 권한은 요청하지 않습니다. 외부 음성인식 앱이 자체적으로 요청하는 권한은 해당 앱에서 관리합니다. 광고 SDK·광고 식별자·사용자 계정 기능은 포함하지 않습니다. 번역 SDK의 진단 및 사용 분석 정보는 아래와 같이 Google에서 처리합니다.

음성입력

사용자가 마이크 아이콘을 누르면 기기에 설치된 음성인식 앱의 입력창을 엽니다. 소복은 직접 녹음하지 않으며 음성 파일을 보관하지 않습니다. 음성인식 제공자는 자체 정책과 사용자의 설정에 따라 음성이나 관련 데이터를 처리하거나 서버에 전송할 수 있습니다. 소복이 돌려받은 인식 문장은 메모리에서만 결과 확인에 사용하며, 사용자가 입력 버튼을 누르고 원래 입력 대상이 확인될 때만 입력란에 적용합니다. 취소·만료·입력 대상 변경 시 결과를 버립니다.

Google Translate를 이용한 번역

번역 아이콘을 누르면 사용자가 선택한 텍스트 또는 현재 입력란의 문장을 기기 안에서 읽습니다. Google ML Kit의 기기 내 번역을 사용하며, 번역 원문과 결과 문장은 기기에서 처리되고 번역을 위해 Google 서버로 전송되지 않습니다. 문장과 결과는 파일에 저장하지 않으며 패널을 닫거나 입력 대상이 바뀌면 메모리에서 비웁니다. 결과는 사용자가 적용을 누를 때만 원래 입력란에 반영합니다.

언어팩은 사용자가 다운로드 버튼을 누를 때 Google에서 받아 기기에 보관합니다. Google ML Kit SDK는 기기 제조사·모델·OS·앱 버전, 설치 식별자, 처리 지연 시간, 설정한 원문·목표 언어, 입력·출력 길이, 모델 버전·다운로드·초기화·오류·사용 이벤트를 진단과 사용 분석 목적으로 Google에 전송합니다. 이 통신은 HTTPS로 암호화됩니다. SDK의 원격 구성과 설치 식별 기능에 Firebase가 사용됩니다. SDK의 원격 구성 과정에서 기기의 언어·지역(로캘 국가 코드)·시간대, 플랫폼·OS 버전, 앱 ID·패키지명·SDK 버전을 처리할 수 있습니다. 로캘 국가 코드는 사용자가 설정한 지역 정보이며 GPS 위치를 읽는 기능은 사용하지 않습니다. 소복은 이 진단 정보를 자체 서버로 받지 않습니다. 자세한 내용은 Google ML Kit 데이터 처리 안내와 Google 개인정보처리방침을 확인하세요.

이 앱은 Google Translate에서 제공하는 기기 내 번역 기술을 사용합니다. 자동 번역에는 오류가 있을 수 있으며 정확성을 보장하지 않으므로 적용 전에 결과를 확인하세요.

4. 개인정보의 공유 및 보유

키보드 입력 내용을 자동으로 수집·서버 보관·판매하거나 제3자에게 공유하지 않습니다. 기기에 저장된 설정은 사용자가 삭제할 때까지 유지됩니다.

5. 이용자의 선택

앱에서 소리와 진동을 끄거나 설정을 초기화할 수 있습니다. 안드로이드 설정에서 소복 키보드를 언제든 비활성화할 수 있습니다. 소복의 체험 입력란에 적은 글도 외부로 전송하거나 영구 저장하지 않습니다.

6. 문의

아이디어·문의 화면에 직접 작성한 내용은 사용자가 메일 앱에서 전송할 때 아래 이메일로 전달됩니다. 앱은 문의 초안을 저장하지 않으며 키보드 입력 내용, 기기 정보나 진단 기록을 자동으로 첨부하지 않습니다. 문의 시 발신 이메일 주소와 직접 작성한 문의 내용을 받으며, 문의 확인과 답변에 사용합니다. 키보드 입력 내용은 자동으로 포함되지 않습니다. 문의 정보의 삭제를 원하면 아래 이메일로 요청할 수 있습니다. 이메일의 전송·보관에는 이용하는 메일 서비스의 정책이 적용됩니다.
