소복 개인정보 처리방침

시행일: 2026년 10월 28일 · 붙여넣기 표시 기능 추가

1. 입력 정보의 처리

소복은 사용자가 누른 키를 현재 입력 중인 앱에 전달하기 위해 처리합니다. 한글 조합에 필요한 짧은 입력 버퍼는 메모리에서만 유지하며 입력 종료·입력 대상 전환 시 비웁니다. 추천 단어를 켠 경우 현재 단어를 기기 안의 기본 사전과 비교하며, 사용자 사전을 학습하거나 추천에 사용한 단어를 저장하지 않습니다. 복사한 항목 붙여넣기가 켜져 있으면 키보드가 열린 동안 현재 클립보드의 텍스트 또는 사진을 기기 안에서 읽어 붙여넣기 칸에 표시합니다. 비밀번호 입력란에는 표시하지 않으며, 민감한 항목으로 표시된 내용은 미리보기에서 숨깁니다. 사진 미리보기는 메모리에서만 처리합니다. 사용자가 붙여넣기를 눌렀을 때만 현재 입력 중인 앱에 텍스트 또는 사진을 전달합니다. 사진은 해당 입력란이 사진 입력을 지원해야 하며 일시적인 읽기 권한을 함께 전달합니다. 클립보드 이력을 저장하거나 서버에 전송하지 않고, 키보드가 닫히면 표시 중인 내용을 비웁니다. 입력한 문장, 비밀번호, 연락처, 위치, 기기 식별자를 저장하거나 외부에 전송하지 않습니다. 입력을 전달받는 상대 앱의 데이터 처리는 해당 앱의 개인정보 처리방침에 따릅니다.

사진 기준 키 위치 맞춤

사용자가 파일 선택창에서 직접 선택하거나 ‘복사한 캡처 사용’을 눌러 불러온 키보드 전체 화면 캡처를 기기 안에서 일시적으로 읽고 키 표면의 사각형 좌표를 분석합니다. 사진 속 문장을 해독하거나 입력 내용을 학습하지 않습니다. 사진을 앱 파일로 복사하거나 서버로 전송하지 않으며, 적용 또는 화면 종료 시 표시용 사진을 메모리에서 해제합니다. 사용자가 확인 후 적용한 키 위치·크기와 화면 비율만 설정으로 저장합니다. 실제 터치 영역은 인접 키 사이를 나누어 구성하며, 다른 키보드 앱의 내부 터치 설정을 읽지 않습니다.

2. 기기 안에 저장되는 설정

선택한 디자인과 소리, 볼륨, 진동, 무음 모드 설정, 키보드 높이·배열 기준·하단 여백·기존 키보드에서 측정한 표시 높이·시스템 하단 높이·숫자 줄 유무·상단 도구 높이·하단 여백, 입력 언어, 화면 모드, 사진 기준 키 위치·크기·화면 비율, 도구·추천·이모지·숫자 줄·복사한 항목 표시, 길게 누르기, ASMR, 입체모드 설정만 기기 안에 저장합니다. 서버에 저장하지 않으며 클라우드 백업과 기기 간 데이터 이전을 사용하지 않습니다. 앱 삭제 또는 기기 설정의 앱 데이터 삭제로 지울 수 있습니다.

3. 권한과 외부 서비스

앱은 인터넷, 마이크, 카메라, 연락처, 위치, 파일 접근 권한을 요청하지 않습니다. 키 입력 시 진동을 위한 진동 권한과 안드로이드 시스템의 키보드 연결 기능만 사용합니다. 광고·분석 SDK, 광고 식별자, 사용자 계정 기능이 없습니다.

4. 개인정보의 공유 및 보유

키보드 입력 내용을 자동으로 수집·서버 보관·판매하거나 제3자에게 공유하지 않습니다. 기기에 저장된 설정은 사용자가 삭제할 때까지 유지됩니다.

5. 이용자의 선택

앱에서 소리와 진동을 끄거나 설정을 초기화할 수 있습니다. 안드로이드 설정에서 소복 키보드를 언제든 비활성화할 수 있습니다. 소복의 체험 입력란에 적은 글도 외부로 전송하거나 영구 저장하지 않습니다.
